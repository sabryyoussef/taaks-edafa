# Trial Balance PDF Report — Use Cases

## Purpose
Generate a trial balance PDF by account, including initial balances (before Start Date) and current period movements.

## Typical use cases
- Monthly trial balance snapshot for finance review.
- Compare posted-only vs including drafts (depending on the selected State).
- Review balances limited to selected journals.

## When to use
- You want a PDF trial balance report that can be shared internally or attached to audit workpapers.

## When not to use
- You need interactive drill-down from report lines to journal items (this is a PDF report).
- You need a fully standard Odoo accounting report with built-in filters (use standard Odoo reports).
