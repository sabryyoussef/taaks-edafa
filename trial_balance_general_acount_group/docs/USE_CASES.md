# General Trial Balance with Account Groups — Use Cases

## Purpose
Generate a general trial balance PDF filtered by selected **Account Groups**, showing initial balances, movements, and account type display.

## Typical use cases
- Produce a grouped/general trial balance for management review.
- Focus reporting on a subset of the chart of accounts using Account Groups.
- Print an Arabic-labeled report layout for internal accounting teams.

## When to use
- Your chart of accounts uses Account Groups and you want a PDF filtered by those groups.

## When not to use
- You need the report grouped/aggregated by group totals (this report filters by group but outputs accounts).
- You need a standard Odoo trial balance with interactive filters.
