# Custom Reports — Use Cases

## Purpose
Generate an “Employee Custody Report” style PDF that summarizes partner-level debit/credit and balances for a selected account over a date range.

## Typical use cases
- Reconcile employee/partner custody movements on a clearing account for a specific period.
- Review partner balances for an account before closing a month.
- Produce an internal PDF snapshot for audit/supporting documents.

## When to use
- You track custody/loan-like movements per partner using journal entries on a specific account.

## When not to use
- You need a full trial balance for all accounts (use the Trial Balance modules instead).
- You need analytic dimensions, multi-currency breakdowns, or tax details (not provided by this report).
